# 評估矩陣結構 (Evaluation Matrix Schemas)

本文件定義方向探索與成果評估的標準結構，確保每次陪跑都有明確的產出與共識。

## 成果評估矩陣 (Outcome Evaluation Matrix)

| 評估面向 (Dimension) | 基礎標準 (Baseline) | 良好標準 (Good) | 優秀標準 (Excellent) |
| :--- | :--- | :--- | :--- |
| **方向清晰度 (Clarity)** | 有提出方向，但略為模糊 | 提出具體方向並與現有公會對齊 | 提出具體方向，並明確定義為什麼選擇該方向 |
| **可行性 (Feasibility)** | 成果範圍過大或不確定 | 成果範圍明確，可在時間內完成 | 成果範圍明確，並有考慮潛在風險與替代方案 |
| **完成度 (Completeness)** | 有開始執行，但未達到完成條件 | 達成設定的完成條件 | 超越完成條件，或產生額外的價值與洞見 |
| **回顧深度 (Reflection)** | 僅敘述做了什麼 | 能指出有效與無效的活動 | 深入分析原因，並能根據回饋調整下一步計畫 |

## 評估守則

1. **客觀紀錄:** 以事實與具體產出為主，避免主觀臆測。
2. **不作診斷:** 不作心理診斷、職涯保證，專注於具體成果與下一步。
3. **本人確認:** 所有評估與下一步規劃，均需經由會員本人確認。
