# 職涯方向與陪跑分類 (Career Guidance Taxonomy)

本文件定義自由工坊（FreeTWAI）中，方向探索與陪跑入門的職能與方向分類。

## 1. 探索階段 (Exploration Phase)

- **現況評估 (Current Status Assessment):** 了解會員目前的職業狀態、過去經驗與可投入時間。
- **目標設定 (Goal Setting):** 釐清會員本週或短期的改變目標。

## 2. 規劃階段 (Planning Phase)

- **方向發想 (Direction Ideation):** 提出兩到三個具體可嘗試的方向。
- **公會對齊 (Guild Alignment):** 將方向與自由工坊現有公會活動對齊，不作過度承諾或心理診斷。

## 3. 執行階段 (Execution Phase)

- **小成果定義 (Micro-Outcome Definition):** 設定一個明確、可完成的小成果與其完成條件。
- **資源盤點 (Resource Mapping):** 確認需要的幫忙與可投入的資源。

## 4. 回顧階段 (Review Phase)

- **成效檢視 (Outcome Review):** 完成後回顧哪些活動有效，哪些需要調整。
- **下一步規劃 (Next Steps Planning):** 調整主力公會或後續學習方向。
